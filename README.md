# 💊 Medicine Reminder

A simple and user-friendly **Medicine Reminder Web Application** built using HTML, CSS, and JavaScript.

The website helps users manage their medicine schedules by adding medicine details, setting reminder times, viewing today's reminders, and tracking medicines.

## 🌐 Live Website

👉 https://yugvadgama24it-dotcom.github.io/medicine-reminder/

## 📌 Project Overview

The Medicine Reminder is a frontend-based web application designed to help users remember their medicines at the scheduled time.

Users can enter:

- Medicine Name
- Dosage
- Start Date
- End Date
- Reminder Time
- Frequency
- Additional Notes

The website also provides an option to enable browser notifications for medicine reminders.

## ✨ Features

### 💊 Add Medicine
Users can add a medicine by entering its:

- Name
- Dosage
- Start date
- End date
- Reminder time
- Frequency
- Additional notes

### 🔔 Browser Notifications
Users can enable browser notifications to receive medicine reminder alerts.

### 📅 Today's Reminders
The website displays medicines scheduled for the current day.

### ✅ Mark Medicine as Taken
Users can mark a medicine as:

- Taken
- Pending

### 🗑️ Delete Medicine
Users can remove medicines from their reminder list.

### 💾 Local Storage
Medicine information is stored in the browser using JavaScript LocalStorage.

### 📱 Responsive Design
The website is designed to work on:

- Desktop
- Laptop
- Tablet
- Mobile devices

## 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| HTML5 | Creates the structure of the website |
| CSS3 | Provides styling and responsive design |
| JavaScript | Provides functionality and reminder logic |
| LocalStorage | Stores medicine information in the browser |
| Notification API | Displays browser notifications |
